# Project Instructions

## Goal

Create a Flutter Android application based on the existing React web application.

## React Project

The React project is the visual and functional reference.

Before implementing Flutter UI, inspect the React source code, including:

- Components
- Pages
- CSS/Tailwind styles
- Assets
- Icons
- Fonts
- Routing
- Animations
- Responsive layouts

Do not modify the React project.

## Flutter Project

The Flutter application is the implementation target.

Use:
- Flutter
- Dart
- Native Flutter widgets

Keep the Flutter code organized and reusable.

## Design Conversion

Recreate the React design as closely as practical.

Preserve:
- Colors
- Typography
- Spacing
- Border radius
- Shadows
- Cards
- Buttons
- Icons
- Images
- Visual hierarchy

Adapt desktop layouts appropriately for Android rather than simply shrinking them.

## Navigation

Recreate the relevant React routes and navigation flow in Flutter.

Do not invent unnecessary pages.

## Assets

Reuse assets from the React project whenever possible.

Do not create replacement assets when an equivalent existing asset is available.

## Workflow

Before coding:

1. Inspect the React project.
2. Identify the relevant page.
3. Identify reusable components.
4. Identify assets.
5. Understand the responsive behavior.
6. Implement the Flutter equivalent.
7. Run the Flutter application.
8. Check for overflow and layout problems.
9. Fix visual inconsistencies.

## Important

Do not redesign the UI unless explicitly requested.

The React application is the design reference.
